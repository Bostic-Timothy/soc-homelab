# Evidence

This directory defines the publication boundary for scenario evidence.

Commit only synthetic, intentionally public artifacts such as selected screenshots, redacted command output, generated logs, diagrams, and small representative packet captures. Large or sensitive raw artifacts should remain in private storage and be represented by a manifest or derived excerpt.

Before committing evidence, verify:

- the target was authorized and lab-owned
- identities and data are fictional
- no credentials, tokens, keys, or endpoints are exposed
- timestamps and context support the stated conclusion
- the artifact does not reproduce proprietary course material
